# Student Performance Analyzer

A beginner Python project that uses NumPy to analyze
student marks and generate performance reports.

## Features

- Display student marks
- Calculate total and average marks
- Find the overall topper
- Calculate subject-wise averages
- Find the highest and lowest marks in each subject
- Identify subject toppers
- Filter students based on average marks
- Menu-driven interface

## Technologies Used

- Python
- NumPy

## How to Run

1. Install Python.
2. Install NumPy using:

   pip install numpy

3. Run the program:

   python student_performance_analyzer.py
